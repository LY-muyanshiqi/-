# 相似日加权预测 — 原理总结

## 1. 算法名称

**相似日加权平均法**（Similar Day Weighted Averaging）

## 2. 核心步骤

| 步骤 | 操作 |
|------|------|
| **特征提取** | 逐时天气数据聚合为逐日特征：最高温、最低温、降水量、总辐射、云量、风速 |
| **标准化** | z-score 标准化（`(x-μ)/σ`），消除量纲差异 |
| **距离计算** | 曼哈顿距离（温度差异 ×5 放大）+ 离散因子（季节、星期、降水、日期衰减） |
| **相似度** | `相似度 = e^(-距离/σ)`，σ 为候选池距离中位数 |
| **加权平均** | `预测负荷(h) = Σ(相似度_i × 负荷_i(h)) / Σ(相似度_i)` |

## 3. 因子权重（基于 395 天实际数据标定）

| 因子 | 权重 | 依据 |
|------|:---:|------|
| 日最低温偏差 | 25% | Pearson r=0.694，夜间基线最强 |
| 日最高温偏差 | 20% | Pearson r=0.569，制冷负荷主驱动 |
| 降水匹配 | 18% | 雨天负荷反增约 10%，需区分干湿模式 |
| 季节匹配 | 12% | 秋季 r=0.76 vs 夏季 r=0.07，跨季节差异大 |
| 日期距离衰减 | 10% | 90 天内无衰减，之后指数衰减 |
| 露点/体感偏差 | 10% | r=0.673，华南高湿环境下体感优于干球 |
| 星期类型匹配 | 5% | 差异仅 0.7%，工业负荷连续性极高 |

## 4. 预测公式

```
P̂(h) = (s₁ × L₁(h) + s₂ × L₂(h) + s₃ × L₃(h)) / (s₁ + s₂ + s₃)
```

- `P̂(h)`：目标日第 h 小时预测负荷（MW）
- `s_i`：第 i 个相似日的相似度（0-100%）
- `L_i(h)`：第 i 个相似日第 h 小时的实际负荷（MW）

## 5. 输出格式

Excel 转置表：行 = 24 小时，列 = 3 个相似日实际负荷 + 1 列预测负荷

| 小时 | 相似日_日期1 | 相似日_日期2 | 相似日_日期3 | 预测_目标日期 |
|------|:---:|:---:|:---:|:---:|
| 00h | L₁(0) | L₂(0) | L₃(0) | P̂(0) |
| ... | ... | ... | ... | ... |
| 23h | L₁(23) | L₂(23) | L₃(23) | P̂(23) |

## 6. 数据覆盖范围

- 预计算：575 天（2025-01-01 ~ 2026-07-29）
- 历史日期查表 < 1 秒
- 未来日期用侧边栏预报天气实时匹配
- 无预报日期降级为同季节最近 3 天

## 7. 优缺点

| 优点 | 缺点 |
|------|------|
| 可解释性强，能追溯预测依据 | 极端天气下候选池可能不足 |
| 不需要训练模型 | 无法捕捉长期产能变化 |
| 对负荷模式突变有一定适应性 | 精度不如深度学习模型 |
| 实现简单，运行快速 | 依赖历史数据覆盖度 |
